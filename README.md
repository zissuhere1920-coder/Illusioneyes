# 🤖 IllusionEyes - Telegram Group Manager Bot

**IllusionEyes** is an advanced Telegram group management bot with powerful features like warnings, mutes, bans, filters, notes, and more.

---

## ✨ Features

| Feature | Description |
|---------|-------------|
| 👥 **Admins** | View all group admins |
| 🟢 **Online** | See online members |
| 📊 **Group Info** | Group statistics |
| ⚙️ **Settings** | Toggle features |
| 🔰 **Warnings** | Warn users |
| 🔇 **Mute** | Mute users |
| 🚫 **Ban/Kick** | Ban or kick users |
| 📝 **Filters** | Auto-reply filters |
| 📋 **Notes** | Save important notes |
| 💡 **Suggestions** | User suggestions |
| 👑 **Promote/Demote** | Admin management |

---

## 🚀 Commands
/admins - List all admins
/online - View online members
/groupinfo - Group details
/settings - Group settings
/warn @user - Warn a user
/mute @user 5m - Mute a user
/unmute @user - Unmute a user
/ban @user - Ban a user
/unban @user - Unban a user
/kick @user - Kick a user
/filter word reply - Add auto-filter
/note name text - Save a note
/suggest idea - Submit suggestion
/promote @user - Promote to admin
/demote @user - Demote from admin
/stats - Bot statistics
/welcome msg - Set welcome message
/goodbye msg - Set goodbye message
