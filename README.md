# 🤖 IllusionEyes - Telegram Group Manager Bot

**IllusionEyes** is an advanced Telegram group management bot with powerful features like warnings, mutes, bans, filters, notes, and more.

---

## ✨ Features

| Feature | Description |
|---------|-------------|
| 👥 **Admins** | View all group admins |
| 🟢 **Online** | See online members |
| 📊 **Group Info** | Group statistics |
| ⚙️ **Settings** | Toggle features |
| 🔰 **Warnings** | Warn users |
| 🔇 **Mute** | Mute users |
| 🚫 **Ban/Kick** | Ban or kick users |
| 📝 **Filters** | Auto-reply filters |
| 📋 **Notes** | Save important notes |
| 💡 **Suggestions** | User suggestions |
| 👑 **Promote/Demote** | Admin management |
